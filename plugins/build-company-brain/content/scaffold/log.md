# Log

One dated line per filing, change, decision or correction, newest last. Never edited, only added to.
`(approved)` marks a change the owner said yes to. A `filed` line names every page the material touched; a file still in `inbox/` hasn't been brought in yet; `edit by owner` lines record the owner's own edits. `check-brain` lines record each finding and what the owner decided; `correction →` lines, where a correction went.
