# Log

One dated line per filing, change, decision or correction, newest last. Never edited, only added to.
`(approved)` marks a change the owner said yes to. A `filed` line names every page the material touched; an `inbox/` or `private/` file with no `filed` line hasn't been brought in yet. `check-brain` lines record each finding and what the owner decided; `correction →` lines, where a correction went.
