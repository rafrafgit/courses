# Log

One dated line per filing, change, decision or correction, newest last. Never edited, only added to.
`(approved)` marks a change the designer said yes to. A `filed` line names every page the material touched; a file still in `inbox/` hasn't been brought in yet; `edit by owner` lines record the designer's own edits. `check-brain` lines record each finding and what the designer decided; `correction →` lines, where a correction went and the rule's first words.
