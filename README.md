# Courses

Learn AI-native work by doing it: each course runs inside Claude Code, on your own business, with Dawn as your mentor.

## Install

You need Claude Code and a paid Claude plan.

1. In Claude Code, add the marketplace, then press Enter:
   ```
   /plugin marketplace add rafrafgit/courses
   ```
2. Install Dawn, then press Enter:
   ```
   /plugin install dawn@courses
   ```
3. Type `/exit`. Make a new folder for your business, open Claude Code in it, and type `/dawn:mentor`. Dawn, your mentor, takes it from there.
